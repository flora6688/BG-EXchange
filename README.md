## 更新网站

1. 解压完整更新包，得到 `docs` 文件夹和此说明。
2. 在 `BG-EXchange` 仓库首页确认分支为 `main`，点击 **Add file → Upload files**。
3. 把解压得到的整个 `docs` 文件夹拖入上传区域。确认文件路径为 `docs/index.html`，不是 `docs/docs/index.html`。
4. 选择 **Commit directly to the main branch**，点击 **Commit changes**。
5. 在 **Settings → Pages** 中使用 **Deploy from a branch → main → /docs**。
6. 等待 **Actions** 中最新的 Pages 部署显示绿色成功，再打开上面的访问地址。
